# DominanceHierarchyDifferences

This repository contains the data and the code required to reproduce the analyses in the manuscript: "Lucas Spicher, Elise Huchard, Dieter Lukas (2026) Dominance hierarchies are structured similarly in females and males across primate groups. Royal Society Open Science https://doi.org/10.1098/rsos.261976". 

The main script for the analyses is "Analyses_SexBias_Hierarchies_FINAL.R", which loads the data from the file "Comparative_primate_steepness_values_clean.csv". The main variables in that file are the measures of the steepness, the linearity (h-index), and the directional consistency index (DCI) of the dominance hierarchies of female and male primates. These values were calculated for the dominance interaction matrices that are included in the "EloSteepness.data" package in R available at https://github.com/gobbios/EloSteepness.data. For an example calculation, see "Example_Bonobo_steepness.Rmd". The phylogenetic tree for the comparative analyses is in the file "Upham2019MammalPhylogeny.nex", it is the consensus tree from Upham, N.S., Esselstyn, J.A. and Jetz, W., 2019. Inferring the mammal tree: species-level sets of phylogenies for questions in ecology, evolution, and conservation. PLoS biology, 17(12), p.e3000494.

The repository also contains the scripts to create the figures and the resulting png files, and the script for the post-hoc analysis on the effect of reduced sampling.
