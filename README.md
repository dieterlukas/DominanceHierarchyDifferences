# DominanceHierarchyDifferences

This repository contains the data and the code required to reproduce the analyses in the manuscript: "Lucas Spicher, Elise Huchard, Dieter Lukas (2026) Dominance hierarchies are structured similarly in females and males across primate groups". 

The main scrpit for the analyses is "Analyses_SexBias_Hierarchies.R", which loads the data from the file "Comparative_primate_steepness_values.csv". The main variables in that file are the measures of the steepness and the linearity (h-index) of the dominance hierarchies of female and male primates. These values were calculated for the dominance interaction matrices that are included in the "EloSteepness.data" package in R. For an example calculation, see "Example_Bonobo_steepness.Rmd". The phylogenetic tree for the comparative analyses is in the file "Upham2019MammalPhylogeny.nex", it is the consensus tree from Upham, N.S., Esselstyn, J.A. and Jetz, W., 2019. Inferring the mammal tree: species-level sets of phylogenies for questions in ecology, evolution, and conservation. PLoS biology, 17(12), p.e3000494.
